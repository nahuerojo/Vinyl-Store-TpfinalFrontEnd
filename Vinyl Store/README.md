# Vinyl Store 🎵

Tienda online de vinilos clásicos y modernos. Proyecto final del curso de Front End con JavaScript.

## Tecnologías usadas

- HTML5 semántico
- CSS3 con Flexbox, Grid y Media Queries
- JavaScript (DOM, eventos, localStorage, fetch)
- Formspree para el formulario de contacto
- Git y GitHub para control de versiones
- Netlify/GitHub Pages para hosting

## Instalación

1. Cloná el repositorio
2. Abrí `index.html` en tu navegador o desplegá en Netlify

## Funcionalidades

- Consumo de API simulada (products.json)
- Carrito de compras dinámico y persistente
- Formulario de contacto validado
- Responsive y accesible
